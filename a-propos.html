LaBible.app · LSG 1910
✦ Présentation

LaBible.app est une application web progressive (PWA) permettant de lire la Bible Louis Segond 1910 (LSG 1910) sur tous vos appareils, même hors connexion.

Ce texte biblique est dans le domaine public. Aucune inscription, aucun compte, aucune publicité n'est requise.

✦ Fonctionnalités

Lecture

Naviguez livre par livre, chapitre par chapitre. Utilisez le plan de lecture annuel pour lire toute la Bible en un an.

Recherche

Accédez à n'importe quel verset par référence : Jn 3:16, Jean 3:16, Ps 23:1.

Favoris

Sauvegardez jusqu'à 200 versets dans vos favoris, accessibles à tout moment.

Partage

Partagez n'importe quel verset sous forme d'image prête pour les réseaux sociaux.

Mode hors ligne

Une fois installée, l'application fonctionne sans connexion internet.

✦ Installation

Android / Chrome

Un bouton « 📲 Installer » apparaît automatiquement dans la barre de navigation. Appuyez dessus pour installer l'application sur votre écran d'accueil.

iPhone / Safari

Appuyez sur le bouton Partager (carré avec flèche), puis sur Ajouter à l'écran d'accueil.
